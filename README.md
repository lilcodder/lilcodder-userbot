# lilcodder-userbot
Модульный Telegram userbot написанный на Pyrogram

# Как установить?
Установите ядро app.py и requirements.txt, запустите бота и авторизируйтесь через свой Telegram аккаунт.

# Как использовать?
Стандартный набор команд:
.ub u / .ub update - обновляет базу данных модулей из директории /modules
.ub restart - перезапускает Userbot

# Как устанавливать модули?
Положите файл модуля lilcodder userbot в директорию /modules (создается автоматически) и пропишите в Telegram .ub u / .ub update. Программа поставит зависимости модуля и пропишет его команды внутрь ядра.

# Как писать свои модули?
Изучите то, как устроены другие модули и их параметры. Напишите свой файл .py и положите его внутрь директории /modules и обновите базу данных модулей. (Полная документация появится позже)
